## Summary
Next.js 15+ fetch() is uncached by default — the opposite of v14. Pages re-render on every request unless you opt into caching with { next: { revalidate: N } } or { cache: 'force-cache' }. Most blog posts and muscle memory predate this flip. Lead templates with explicit { cache: 'no-store' } when SSR is the intent. See .agent/philosophy/NEXTJS-PATTERNS.md §D.
