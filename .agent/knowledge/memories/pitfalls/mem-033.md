## Summary
Next.js 16 renames middleware.ts to proxy.ts at project root. Same matcher API and NextRequest/NextResponse, but middleware.ts is deprecated. Codemod: npx @next/codemod@canary middleware-to-proxy . Also in v15+: params and searchParams are Promises — must await them in pages, layouts, and route handlers. Route Handler context type is inferred from the file path: collection routes get Promise<{}>, dynamic routes get Promise<{id: string}>. Hardcoding the dynamic shape on a collection route fails `next build` type-check. See .agent/philosophy/NEXTJS-PATTERNS.md §A, §E, §H.
